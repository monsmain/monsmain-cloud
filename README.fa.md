## چرا monsmain-cloud؟

- **نصب با یک کلیک.** لینک نصب‌کننده را باز کنید، یک توکن بچسبانید، تمام. بدون ترمینال، بدون `wrangler`، بدون کپی‌کردن کلید.
- **همه‌چیز مال خودتان است.** فایل‌ها، دیتابیس و تنظیمات روی حساب کلودفلر خودتان می‌مانند. نصب‌کننده توکن شما را ذخیره نمی‌کند.
- **دو موتور ذخیره‌سازی.** تلگرام برای فایل‌های کوچک و Cloudflare R2 برای فایل‌های بزرگ.
- **پنل + ربات.** فایل‌ها را از مرورگر یا مستقیم از تلگرام مدیریت کنید.
- **مناسب موبایل و کامپیوتر.** رابط ریسپانسیو، نوار تب پایین در موبایل و قابل نصب به‌صورت برنامه.

| 🔗 **لینک اشتراکی** | برای هر فایل یک لینک عمومی که هر زمان لغوش کنید. لینک‌های دانلود ربات امضاشده‌اند و بعد از ۱ ساعت منقضی می‌شوند |
| 🗑️ **سطل زباله** | حذف ← سطل زباله ← بازیابی یا حذف دائمی بعد از تأیید. **بعد از ۳۰ روز خودکار پاک می‌شود** |

| 🤖 **ربات تلگرام** | `/start`، `/menu`، آپلود با فرستادن فایل یا لینک، فهرست / اشتراک / حذف، سطل زباله با تأیید، `/setpass` |

| 🔐 **امنیت** | بخش [امنیت](#امنیت) را ببینید |

## چطور کار می‌کند

```text
 Browser / PWA ───┐
                  ├──►  Worker (this repo)  ──►  KV        file index + settings
 Telegram bot ────┘            │
                               ├──►  R2        large files (up to 10 GB each)
                               └──►  Telegram  small files (up to 20 MB each)
```

1. **نصب‌کننده** (لینک بالا) با یک توکن API کلودفلر که با یک کلیک می‌سازید، روی حساب **خودتان** یک دیتابیس KV و در صورت تمایل یک باکت R2 می‌سازد و این پنل را به‌عنوان Worker آپلود می‌کند.
2. پنل جدیدتان را باز می‌کنید و **توکن ربات** تلگرام، **آیدی عددی** و یک رمز عبور را وارد می‌کنید.
3. پنل یک فهرست کوچک از فایل‌ها را در KV نگه می‌دارد. خود فایل‌ها در تلگرام (تا ۲۰ مگابایت) یا R2 (تا ۱۰ گیگابایت) ذخیره می‌شوند.
4. ربات تلگرام از طریق وب‌هوک با همین Worker صحبت می‌کند، پس همه‌چیز را از داخل چت هم می‌توانید مدیریت کنید.

## شروع سریع

> فقط یک حساب کلودفلر و یک حساب تلگرام لازم دارید.

### ۱ · آماده‌سازی تلگرام (۲ دقیقه)

1. **[@BotFather](https://t.me/BotFather)** را باز کنید ← `/newbot` ← **توکن ربات** (`123456789:AA…`) را کپی کنید.
2. **[@userinfobot](https://t.me/userinfobot)** را باز کنید ← **آیدی عددی** خودتان را کپی کنید.
3. ربات تازه‌ساخته را باز کنید و **Start** بزنید (ربات قبل از این نمی‌تواند به شما پیام بدهد).

### ۲ · نصب پنل

1. نصب‌کننده را باز کنید: **<https://installer-cloud.monsmain.workers.dev>**
2. روی **ساخت خودکار توکن** بزنید — صفحه‌ی کلودفلر با همه‌ی دسترسی‌های لازم که از قبل انتخاب شده‌اند باز می‌شود.
3. روی **Continue to summary ← Create Token** بزنید، توکن را کپی کنید و در نصب‌کننده بچسبانید.
4. یک نام انتخاب کنید (پیش‌فرض `monsmain-cloud`)، اگر R2 روی حسابتان فعال است تیک **R2** را نگه دارید و **نصب** را بزنید.
5. بعد از پایان نصب روی **باز کردن پنل** بزنید. این لینک شامل کلید راه‌اندازی یک‌بارمصرف شماست؛ تا پایان مرحله‌ی ۳ محرمانه نگهش دارید.
6. توکن API را از کلودفلر (**My Profile ← API Tokens**) حذف کنید؛ نصب‌کننده دیگر به آن نیاز ندارد.

### ۳ · تکمیل راه‌اندازی روی پنل

توکن ربات، آیدی عددی خودتان و یک رمز عبور (حداقل ۸ کاراکتر) را وارد کنید. پنل توکن را بررسی می‌کند، یک پیام تأیید در تلگرام برایتان می‌فرستد، وب‌هوک را وصل می‌کند و منوی دستورات `/` ربات را می‌سازد. تمام 🎉

> **نکته‌ی R2:** R2 را باید یک بار در داشبورد کلودفلر فعال کنید (ممکن است کلودفلر کارت بانکی بخواهد؛ پلن رایگان ۱۰ گیگابایت دارد). بدون R2 هم پنل با موتور تلگرام کار می‌کند و بعداً می‌توانید نصب‌کننده را دوباره اجرا کنید تا اضافه شود.

## کار با پنل

| تب | کارهایی که می‌شود کرد |
| --- | --- |
| **آپلود** | موتور را انتخاب کنید، فایل را رها کنید یا لینک مستقیم بچسبانید. برای تلگرام می‌توانید «ارسال به‌صورت مدیا» را انتخاب کنید (تلگرام عکس‌ها را فشرده می‌کند؛ برای نگه‌داشتن فایل اصلی خاموشش کنید). با R2 مصرف زنده را می‌بینید و قبل از عبور از سقف هشدار می‌گیرید. |
| **درایو من** | پوشه بسازید، جست‌وجو کنید، فایل را باز / پیش‌نمایش کنید، **اشتراک‌گذاری** (کپی لینک، لغو اشتراک)، **انتقال** و حذف. با **انتخاب** می‌توانید چندین فایل را یک‌جا منتقل یا حذف کنید. تصاویر کوچک پیش‌نمایش دارند. |
| **سطل زباله** | بازیابی یا **حذف برای همیشه** (با تأیید). روی هر مورد نوشته شده چند روز تا پاک شدن خودکار مانده است. |
| **تنظیمات** (چرخ‌دنده) | تغییر توکن ربات، آیدی عددی و سقف R2 (به گیگابایت، `0` = بدون هشدار). نسخه‌ی پنل و وضعیت R2 هم آنجا نمایش داده می‌شود. |

**رمز را فراموش کرده‌اید؟** در صفحه‌ی ورود روی *فراموشی رمز عبور* بزنید، رمز جدید را وارد کنید و کد ۶ رقمی‌ای را که ربات می‌فرستد وارد کنید (۱۰ دقیقه اعتبار). یا به ربات بنویسید `/setpass رمز_جدید`.

### نصب به عنوان برنامه (PWA)

- **اندروید / Chrome / Edge:** روی **نصب برنامه** در نوار بالا بزنید (یا از پیشنهاد نصب مرورگر استفاده کنید).
- **آیفون / آیپد:** در Safari از **Share ← Add to Home Screen** استفاده کنید.

## کار با ربات

| این کار را بکنید | نتیجه |
| --- | --- |
| `/start` یا `/menu` | منوی اصلی (فایل‌ها، سطل زباله، راهنمای رمز، آیدی عددی، زبان) |
| فرستادن یک فایل (تا ۲۰ مگابایت) | تأیید می‌گیرد و بعد ذخیره می‌کند |
| فرستادن یک لینک مستقیم | آن را داخل R2 دانلود می‌کند (تا ۲۰۰ مگابایت از طریق ربات — برای فایل بزرگ‌تر از پنل استفاده کنید) |
| **فایل‌های من** | هر صفحه ۵ مورد: باز کردن (فایل یا لینک ۱ ساعته را می‌فرستد)، 🔗 اشتراک / 🚫 لغو اشتراک، 🗑️ حذف |
| **سطل زباله** | ♻️ بازیابی، ❌ حذف دائمی (با تأیید) |
| `/setpass رمز_جدید` | رمز پنل را عوض می‌کند، همه‌ی نشست‌ها را می‌بندد و پیام شما را پاک می‌کند |

ربات **فقط به ادمین** (همان آیدی عددی که وارد کردید) پاسخ می‌دهد؛ بقیه فقط پیام «ربات خصوصی است» می‌گیرند.

## به‌روزرسانی · حذف

- **به‌روزرسانی:** نصب‌کننده را دوباره باز کنید و **همان نام** را بزنید — فایل‌ها و تنظیمات حفظ می‌شوند.
- **حذف:** Worker، namespace با نام `<name>-kv`، باکت R2 با نام `<name>-files` (اول خالی‌اش کنید) را پاک کنید، آدرس `https://api.telegram.org/bot<TOKEN>/deleteWebhook` را باز کنید و توکن API را حذف کنید.

## امنیت

- کوکی نشست امضاشده با `HttpOnly`، `Secure` و `SameSite=Lax`؛ با تغییر رمز همه‌ی نشست‌ها باطل می‌شوند
- هش رمز با PBKDF2-SHA256 و salt تصادفی؛ ورود، بازیابی و راه‌اندازی محدودیت تعداد تلاش دارند
- محافظت در برابر CSRF با `Sec-Fetch-Site` / `Origin`
- ربات تک‌ادمین: هم `secret_token` وب‌هوک و هم چک آیدی عددی
- کلید راه‌اندازی یک‌بارمصرف (`SETUP_TOKEN`) تا کسی نتواند پنل تازه‌نصب را تصاحب کند
- آپلود از لینک، آدرس‌های محلی و خصوصی را مسدود می‌کند (محافظت SSRF)
- نام فایل‌ها در رابط escape می‌شوند؛ فایل‌های HTML / SVG / JS همیشه به‌صورت attachment با sandbox CSP و `nosniff` سرو می‌شوند
- فایل‌های خصوصی نیاز به ورود دارند؛ لینک اشتراکی UUID غیرقابل‌حدس است و با لغو اشتراک یا انتقال فایل به سطل زباله از کار می‌افتد
- نصب‌کننده توکن کلودفلر شما را ذخیره یا لاگ نمی‌کند

## محدودیت‌ها

- **تک‌ادمین** — هر پنل یک مالک دارد.
- **موتور تلگرام:** ۲۰ مگابایت برای هر فایل (محدودیت Bot API). تلگرام عکس‌هایی که به‌صورت مدیا فرستاده می‌شوند را فشرده می‌کند.
- **موتور R2:** در رابط تا ۱۰ گیگابایت برای هر فایل. محاسبه‌ی مصرف تا حدود ۵۰ هزار آبجکت دقیق است (بیشتر از آن *partial* علامت می‌خورد).
- فهرست فایل‌ها یک سند JSON داخل KV است (سقف ۲۵ مگابایت) — برای استفاده‌ی شخصی کاملاً کافی است، نه برای میلیون‌ها فایل.
- رابط پنل Tailwind و فونت وزیرمتن را از CDNهای عمومی بارگذاری می‌کند؛ اگر در شبکه‌ی شما مسدود باشند صفحه ممکن است بدون استایل دیده شود.
- «تصویر کوچک» همان فایل اصلی (تا ۴ مگابایت) است که تنبل (lazy) بارگذاری و ۲۴ ساعت کش می‌شود — تغییر اندازه‌ی واقعی به Cloudflare Images نیاز دارد.

## عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| *تلگرام این توکن ربات را قبول نکرد* | کل توکن را از BotFather کپی کنید؛ صفحه دلیل خود تلگرام را داخل پرانتز نشان می‌دهد |
| *ربات نمی‌تواند به این چت پیام بدهد* | ربات را باز کنید و **Start** بزنید، بعد دوباره تلاش کنید؛ آیدی عددی را هم بررسی کنید |
| *فعال‌سازی R2 ممکن نشد* | R2 را در داشبورد کلودفلر فعال کنید و نصب‌کننده را با همان نام دوباره اجرا کنید |
| خطای ۴۰۴ درست بعد از نصب | کلودفلر تا یک دقیقه برای انتشار زمان می‌خواهد — صبر کنید و رفرش کنید |
| خطای *Forbidden* هنگام ثبت فرم | به آخرین نسخه به‌روز کنید (نصب‌کننده را دوباره اجرا کنید) |
| ربات بعد از به‌روزرسانی ساکت است | یک بار پنل را باز کنید — وب‌هوک دوباره ثبت می‌شود |
